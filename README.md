Gender Perspectives: The Philippine Story

A web-based educational platform focused on exploring gender equality, identity, and societal perspectives within the Philippine context. This project aims to promote awareness, inclusivity, and critical understanding of gender-related issues through accessible digital content.

Live Website: Gender Perspectives PH Live Demo
Repository: GitHub Repository

Project Overview

Gender Perspectives: The Philippine Story is designed to present structured and informative content about gender issues, with emphasis on cultural, social, and historical contexts in the Philippines. It serves as an educational resource for students, researchers, and the general public.

The platform translates complex social topics into a clear and accessible web experience using modern front-end development practices.

Objectives
To promote awareness of gender equality and inclusivity
To present Philippine-centered gender perspectives in an educational format
To encourage critical analysis of societal norms and gender roles
To provide accessible digital learning material for users

Installation & Setup

To run the project locally:

git clone https://github.com/SintosDev514/Gender-Perspectives-The-Philippine-Story.git

Navigate to the project directory:

cd Gender-Perspectives-The-Philippine-Story

Run the project using a local development server such as:

XAMPP
Live Server (VS Code Extension)
WAMP / Laragon

Then open in your browser:

http://localhost/
Deployment

This project is deployed using Vercel for fast and reliable hosting.
